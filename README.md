# 🚀 Asteroid Dodger

A simple 2D space game developed using **C#, Windows Forms, and GDI+ Graphics**.

## 🎮 Features

- Spaceship controlled with left and right arrow keys
- Randomly generated asteroids and star background
- Collision detection (Game Over after 3 hits)
- Score: +10 points for each dodged asteroid
- Game timer and hit counter
- Game Over screen with final statistics
- Restart Game button

## 🕹️ How to Play

Use **← →** to move your spaceship and avoid falling asteroids. Earn 10 points for every asteroid you dodge. After 3 collisions, the game ends. Click **Restart Game** to play again.

## 🛠️ Technologies

C# | Windows Forms | .NET Framework | GDI+ | Visual Studio 2022

## ▶️ How to Run

1. Clone or download the repository.
2. Open `AsteroidDodger2.slnx` in Visual Studio.
3. Build and press **F5** to run.
